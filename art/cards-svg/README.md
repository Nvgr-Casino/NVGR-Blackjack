# Card faces

Byron Knoll's **Vector Playing Cards**, as collected at
https://github.com/notpeter/Vector-Playing-Cards (`cards-svg/`, the 52
standard cards; the jokers are not used).

The artwork is released into the public domain (or, where that is not
recognised, under the WTFPL): free to use, change and ship, commercially or
not. Original source: https://code.google.com/archive/p/vector-playing-cards/

These SVGs are the source only. The game ships the WebP images rendered
from them into `public/cards/` by `npm run cards` (`scripts/build-cards.mjs`).
